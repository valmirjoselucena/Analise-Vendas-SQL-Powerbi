# ERP Vendas BI

Projeto completo de Engenharia e Análise de Dados simulando um ERP comercial.

## Objetivos

Este projeto foi desenvolvido para demonstrar conhecimentos práticos em:

- SQL Server
- Modelagem Relacional
- ETL com Python
- Data Warehouse
- Power BI
- Git e GitHub

## Arquitetura

        ▼

        │
        ▼

        ▼

## Tecnologias

- SQL Server

- Pandas
- SQLAlchemy
- Power BI
- Git

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Controle de estoque
- Histórico de preços
- Pedidos
- Pagamentos
- Dashboard Executivo
- Dashboard Comercial
